What the import CSV includes

HS code, product description, unit, quantity, import value and import revenue. The partner file additionally identifies the origin country for each product-country row.

What it does not include

This monthly Customs workbook does not provide individual importer or supplier company names. TradePulse does not infer those fields.

About this Nepal import dataset

The Department of Customs source workbook reports import value and import revenue in Rs thousands. TradePulse preserves the source values and adds a convenience Rs-billion value column. Source total rows are excluded from downloadable tables.

HS codes are stored as text in the CSV so leading zeros remain intact when opened in common spreadsheet and analytical tools.

Frequently asked questions

Where can I download Nepal import data?

Use the CSV buttons on this page for Shrawan FY 2083/84 product-level and product-country import data. The downloads are free and require no account.

Does the import data include HS codes?

Yes. The product files retain official 8-digit HS codes, descriptions, quantities, values and import revenue.

Does this include Nepal importer company names?

No. Company-level importer and supplier names are not fields in this monthly source workbook.

Can I download the whole trade release?

Yes. Use the complete Shrawan ZIP or visit the Nepal trade data download hub.
