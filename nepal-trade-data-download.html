Processing notes

Useful data without hiding the source.

TradePulse cleans the delivery format for analysis while keeping the official values traceable.

01 · Preserve

Official values stay intact

Monetary source values remain in Rs thousands. Added Rs-billion columns are simple unit conversions.

02 · Clean

Total rows are removed

Download tables exclude the source total row so ranking, filtering and aggregation do not double-count totals.

03 · Protect

HS codes stay as text

Leading zeros are preserved so codes such as 01029000 are not silently changed by spreadsheet software.

Frequently asked questions

Can I download Nepal export data for free?

Yes. TradePulse provides the current processed export product and export product-partner CSV files without a sign-up or paywall.

Can I download Nepal import data by HS code?

Yes. The import product CSV contains 4,014 HS-code product rows for Shrawan FY 2083/84, including quantity, import value and import revenue.

Is this official government data?

The underlying figures come from the Department of Customs workbook. TradePulse Nepal is an independent project that processes and presents those figures; it is not an official government publication.

Will more months be added?

The data library is designed to expand as new Department of Customs monthly releases are processed and verified.
